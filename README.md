# Book Library Application

A simple **Book Library** web app built with **Next.js**, **Redux Toolkit**, **TypeScript**, and **Bootstrap CSS**.  
Users can add books as read or unread, view the list of books, filter by read/unread status, and toggle the read status.

---

## Features

- Add new books with title, author, description, and read/unread status
- View list of all books
- Filter books to show all, only read, or only unread
- Mark books as read or unread
- Responsive UI styled with Bootstrap CSS (no JavaScript)
- State management with Redux Toolkit
- Fully typed with TypeScript
